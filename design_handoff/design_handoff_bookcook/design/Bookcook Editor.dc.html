★ Type it · Edit

/new/type/:draftId · /r/:id/edit · RW Draft (mode type | edit, ingredientLines, recipeId) · ParsedIngredient per line. Phone shows one section at a time with a sticky Save recipe bar. Edit is the same screen with the title "Edit recipe".

Paste it · From a link

/new/paste/:draftId · /new/link/:draftId · RW Draft (mode paste | link) → ParsedRecipe (sourceUrl, imageUrl) → Review. Recipe.source = 'web' for links.

Review

/new/review/:draftId · R Draft.recipe · W Recipe (source, lang, createdAt, updatedAt), then deletes the Draft. "Check this" needs ParsedIngredient.needsCheck / ParsedStep.needsCheck and a checkReason (gap 1).
