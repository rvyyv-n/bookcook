The first release of Bookcook: a cookbook you can talk to.

**Use it on the web** at https://bookcook.pages.dev/ and install it from the browser menu to use it like an app, offline too. **On Android**, download `bookcook-1.0.0.apk` below and open it to install. Android will ask you to allow installs from your browser the first time.

## What's in it

- **Tell it** a recipe one question at a time, **just talk** while you cook, or **type, paste or import** one from a link. Check it on one screen before saving.
- **Cook mode**: one step at a time in very large type, read aloud, moved along by voice (next, back, repeat, timer, stop), with several timers at once.
- **Scale servings**, switch metric and imperial, and add ingredients to a **grocery list** grouped by aisle.
- **Ask someone for a recipe** with a link, **share** recipes, **back up** everything to a file, and **print** the family cookbook.
- **Five looks**, light and dark, and three text sizes up to Huge, with a short welcome that sets it up.

## Updates

Bookcook now tells you when there's a new version. On the web, tap **Update** when it's offered (never while you're cooking). On Android, tap **Download** and install the new APK over this one. You can also check any time in **Settings**, under **Check for updates**.

If you installed an earlier test build of the Android app, uninstall it before installing this one: they're signed differently. Uninstalling removes its recipes, so use **Settings → Back up now** first and **Restore** the file afterwards.
